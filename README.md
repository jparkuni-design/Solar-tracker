# Solar Tracker

Arduino-based dual-axis solar tracker using servo motors and LDR sensors, with temperature and humidity monitoring.

## Components
- Arduino nano
- 2x Servo Motors
- 4x LDR Sensors
- Temperature & Humidity Sensor (DHT11)
- Solar Panel

## Features
- Dual-axis automatic solar tracking
- Real-time temperature and humidity monitoring
